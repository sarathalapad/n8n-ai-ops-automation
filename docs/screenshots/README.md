# Screenshots

Placeholder folder for n8n canvas screenshots. To add them:

1. Start the stack (`docker compose up -d`) and import the workflows (see the main README).
2. Open each workflow in the n8n editor, press `Shift+1` / "Zoom to fit", and take a screenshot.
3. Save them here with these names so the README can link them:
   - `01-incident-intake-ai-triage.png`
   - `02-remediation-human-approval.png`
   - `03-daily-ops-digest.png`
   - `99-error-handler.png`
4. Optionally add a screenshot of a successful execution (the green path) of workflow 01.

Before committing, check that no screenshot shows real hostnames, credentials, customer data or chat URLs.
